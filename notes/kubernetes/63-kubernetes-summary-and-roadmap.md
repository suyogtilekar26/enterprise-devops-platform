# 6. Why Labs Come Next

Documentation explains concepts.

Labs build confidence.

Labs answer questions like

- Can you deploy?
- Can you debug?
- Can you recover?
- Can you troubleshoot?
- Can you verify?
- Can you automate?

Without Labs, documentation remains theoretical.
