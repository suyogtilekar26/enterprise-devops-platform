# ArgoCD Hands-on Labs

# Enterprise DevOps Platform

---

# Purpose

This directory contains hands-on ArgoCD labs designed to build practical GitOps skills from beginner to production level.

These labs complement the theory notes, runbooks and incident guides available in this repository.

---

# Target Audience

- DevOps Engineers
- Platform Engineers
- Cloud Engineers
- SRE Engineers
- Kubernetes Administrators
- Students preparing for DevOps interviews

---

# Prerequisites

Before starting these labs, you should have basic knowledge of:

- Linux
- Docker
- Kubernetes
- kubectl
- YAML
- Git
- Helm (Recommended)

# Lab Environment

Recommended Environment

# Lab Objectives

After completing these labs, you will be able to

- Install ArgoCD
- Deploy Applications
- Configure Auto Sync
- Configure Self Healing
- Troubleshoot Production Issues
- Perform Rollbacks
- Implement GitOps Best Practices
- Deploy Multiple Applications
- Manage Multi-Cluster Deployments
- Secure ArgoCD using RBAC
- Handle Production Incidents
