# What is a Helm Chart?

A Helm Chart is a package containing everything required to deploy an application into Kubernetes.

Typical contents include:

- Deployment
- Service
- ConfigMap
- Secret
- Ingress
- HPA
- ServiceAccount
- Values
- Templates

Think of a Chart as a deployable application package.

# Why Did Helm Create So Many Files?

Helm generates a production-ready starter template.

It already includes:

- Deployment
- Service
- Ingress
- HPA
- ServiceAccount
- Helper Templates
- Test Pod

Most enterprise teams customize this template rather than creating charts from scratch.

# Production Best Practices

Do not modify generated templates immediately.

First understand:

- Chart.yaml
- values.yaml
- templates/
- helpers
- release structure

Enterprise teams maintain standard chart templates to ensure consistency across all applications.

---

# Common Mistakes

- Creating charts outside the repository.
- Renaming files manually.
- Deleting templates without understanding their purpose.
- Mixing multiple applications inside one chart.
- Editing generated files before understanding them.

# Interview Questions

## Q1. What is a Helm Chart?

### Answer

A Helm Chart is a packaged Kubernetes application containing templates, configuration values and metadata required to deploy an application consistently across environments.

---

## Q2. Which command creates a Helm Chart?

```bash
helm create <chart-name>
```

Example

```bash
helm create demo-chart
```

---

## Q3. Why do enterprises use standard chart templates?

### Answer

Standard templates ensure consistency, simplify maintenance, reduce deployment errors and make onboarding easier across multiple engineering teams.
